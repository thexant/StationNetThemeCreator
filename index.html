Install your theme ↗
  1. Export your theme as a JSON file.
  2. In StationNet, open SYSOP CONTROL → Station settings and import the file.
  3. Select the theme for the interface, masthead, or both. They are independent selectors.

Or place <id>.json in <STATIONNET_DATA>/themes/ and refresh Station settings. Choose an ID that is not already installed.
